# Axonyx UI 0.0.86 Candidate

Eleven native Foundry editor icons: paragraph, H2, H3, bold, italic, bullet/number
lists, link/unlink, undo/redo. Import from @axonyx/ui/foundry/icons/NameIcon.
Icons use 24x24 viewBox, currentColor strokes, round caps/joins and no fill.
They are embedded Cargo assets and included in npm foundry distribution.
Accessible button names are owned by the consuming toolbar.

Existing themes, finishes and light/dark contracts are unchanged. This is not
a React editor adapter or a Legura Editor package release.
Cargo and npm publication are independent; npm can require interactive 2FA.

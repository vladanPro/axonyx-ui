# Axonyx forged X

Canonical SVG marks based on the approved Foundry pilot reference.
Bronze is the ecosystem mark; gold identifies `.asx`, silver identifies `.ax`.
Transparent background, no enclosing tile, no central dot. Keep the same
silhouette across all finishes. SVG is the source; raster exports are derived.

Web copies live in each site's `public/brand-mark.svg` and `public/favicon.svg`.
Scaffold templates carry the same bronze asset. VS Code also provides darker
file icons for light editor themes and a 256px transparent extension icon.
